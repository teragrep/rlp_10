= Teragrep performance test application for RELP rlp_10

== Features

- Simple to use
- Reports event throughput and latency metrics
- Supports sending specific amount of events spread over multiple RelpClients and EventLoops running in a virtual ThreadPool
- Supports TLS

== Limitations

- Minimal failure tolerance, mostly meant for testing
- Limited usability outside specific testing situations

== How to compile

[source,bash]
----
mvn clean package
----
== How to run

[source,bash]
----
java [-DconfigurationPath=<path>] -jar rlp_10.jar
----
== Configurations

Configurable via `rlp_10.properties` file. Supply path to configuration file with `configurationPath` system property, defaults to `./config/rlp_10.properties`
Example file with default configurations is available at `src/main/resources/config/rlp_10.properties`

[options="header", cols="m,m,a"]
|===
| Property | Default value | Usage

| metrics.window
| 10000
| DropWizard metrics sliding window size (How many data points to consider when calculating latency metrics)

| report.interval
| 1000
| Reporting interval in milliseconds (How often metric information is outputted by a MetricsReport. Currently only applies to SLF4J report)

| report.ratetimeunit
| SECONDS
| TimeUnit to use for reporting rate metrics. (Refer to Java TimeUnit enum constants https://docs.oracle.com/javase/8/docs/api/java/util/concurrent/TimeUnit.html#enum.constant.summary[Javadoc])

| report.durationtimeunit
| MILLISECONDS
| TimeUnit to use for reporting duration metrics. (Refer to Java TimeUnit enum constants https://docs.oracle.com/javase/8/docs/api/java/util/concurrent/TimeUnit.html#enum.constant.summary[Javadoc])

| recordstream.records
| 9223372036854775807
| Number of records to send in total

| delay.duration
| PT0S
| Delay between sending records, in ISO-8601 duration (also referred to as "period") format

| initiator.count
| 1
| Number of clients to use

| initiator.eventloopcount
| 1
| Number of EventLoops to distribute the clients between

| initiator.retryconnectioncount
| 3
| Maximum number of times clients should retry to connect

| initiator.retrytransmissioncount
| 3
| Maximum number of times clients should retry to send a record

| prometheus.port
| 8080
| Prometheus endpoint port

| syslog.appname
| appName
| Appname used in RELP record

| syslog.hostname
| localhost
| Hostname used in RELP record

| socket.hostname
| localhost
| RELP Server target address

| socket.port
| 1601
| Relp Server target port

| timeout.open
| 1000
| RELP Server reconnect interval, in milliseconds

| timeout.payload
| 1000
| RELP Server resend interval, in milliseconds

| transport.tls
| false
| Boolean flag to enable or disable TLS

| transport.keystorepath
| /opt/teragrep/rlp_10/tls/keystore.jks
| Absolute path to keystore for use with TLS. Must be placed within /opt/teragrep/rlp_10

| transport.keystorepassword
| changeit
| TLS keystore password

| transport.truststorepath
| /opt/teragrep/rlp_10/tls/truststore.jks
| Absolute path to truststore for use with TLS. Must be placed within /opt/teragrep/rlp_10

| transport.truststorepassword
| changeit
| TLS truststore password

| transport.protocol
| TLSv1.3
| TLS protocol to be used
|===
